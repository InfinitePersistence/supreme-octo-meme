##### 当前项目5G模块业务系统结构

```
局域网设备
电脑/手机
    ↓
开发板的LAN或WiFi
    ↓
VPP路由、NAT
    ↓
Ethernet6（项目中的5G逻辑端口）
    ↓
5g-modem（Linux中的模组数据网口）
    ↓ USB
5G模块 + SIM卡 + 天线
    ↓ 无线蜂窝信号
运营商基站
    ↓
互联网或专用移动网络
```

作用:

1. 连接运营商移动网络

5G模块包含蜂窝Modem，可以完成手机基带类似的工作：

- 读取SIM卡身份
- 搜索周围基站
- 向运营商网络注册
- 建立4G LTE或5G连接
- 发送和接收蜂窝数据

因此，即使开发板没有接入有线WAN，它也可以通过5G模块获得上联网能力。

## 2. 获得一个数据网口

模块通过USB连接开发板后，Linux会出现两类接口。

控制接口：

```
/dev/ttyUSB2
/dev/ttyUSB3
```

用于发送AT命令，查询和控制模块。

数据接口：

```
5g-modem
```

用于传输真正的IP数据包。

例如：

```
AT+CSQ
```

只能查询信号强度；真正访问网站的数据不会通过 `ttyUSB3`，而会经过 `5g-modem` 网口。

## 3. 使用SIM卡完成身份认证

SIM卡相当于运营商发给用户的网络身份证，包含用户身份和认证信息。

产品支持双卡单待：

- 可以识别SIM1和SIM2
- 可以读取两张卡的IMSI
- 可以判断移动、联通、电信或广电
- 同一时刻只选择一张卡接入网络
- 当前卡不可用时可以切换另一张

代码通过以下AT命令操作：

```
AT+QUIMSLOT=1    选择SIM1
AT+QUIMSLOT=2    选择SIM2
AT+CPIN?         检查SIM是否就绪
AT+CIMI          读取IMSI
```

## 4. 配置APN并建立数据连接

SIM卡注册成功并不等于已经可以访问IP网络，还需要建立数据会话。

这时会使用APN，例如：

```
internet
cmnet
运营商提供的专网APN
```

APN决定设备接入运营商的哪个数据网络。可能是：

- 普通互联网
- 企业专网
- 本地5G专网
- IPv4、IPv6或者双栈网络

项目使用：

```
AT+QICSGP=...
```

配置APN，然后启动：

```
/xbox-env/sbin/quectel-CM
```

`quectel-CM` 是拨号管理程序，负责建立并维护移动数据连接，见 [drv_5g_module.c (line 1462)](/Z:/opt/code/platform/code/RSP/DRIVER/drv_5g_module.c:1462)。

## 5. 获得IP网络能力

拨号成功后，模块可以获得：

- IP地址
- 子网掩码
- 网关
- DNS等网络参数

代码通过：

```
AT+QNETDEVSTATUS=1
```

查询IP、掩码和网关，解析位置在 [drv_5g_module.c (line 1798)](/Z:/opt/code/platform/code/RSP/DRIVER/drv_5g_module.c:1798)。

注意，获得IP不一定意味着获得公网IP。运营商经常分配内网地址，并通过CGNAT统一访问互联网。

## 6. 成为5G路由器

单纯安装模块后，首先获得的是“开发板自身通过5G联网”的能力。

如果再配合项目里的：

- VPP路由
- NAT
- DHCP
- 防火墙
- LAN接口
- WiFi AP

那么局域网设备也可以借助开发板的5G连接上网：

```
手机连接产品WiFi
        ↓
产品把手机流量转发到5G模块
        ↓
通过运营商网络访问外部网络
```

这时整个产品就相当于一台5G CPE或5G工业路由器。

## 7. 获得运行状态监控能力

项目不仅负责拨号，还会持续采集：

- 模块是否上电
- USB设备是否存在
- SIM是否插入
- 当前使用哪张SIM
- SIM所属运营商
- 是否完成网络注册
- 当前连接4G还是5G
- 信号质量
- IP、掩码和网关
- `quectel-CM` 是否运行

这些信息保存在：

```
DRV_5G_MODULE_STATUS
```

之后会提供给Web页面显示。

## 8. 自动恢复和双卡切换

现有代码还实现了一些产品级能力：

- 模块USB拔出后停止拨号
- 模块重新出现后自动初始化
- `quectel-CM`退出后自动拉起
- 双卡时120秒没有网络则切换SIM
- 双卡时信号持续过差则切换SIM
- 网络恢复后通知平台重新启动DHCP流程

提供长期无人值守的连接维护能力。





### **RM500U‌：** 基于 ‌3GPP Release 15‌，16 标准开发，支持NSA和SA双模组网。  

## NSA：非独立组网

NSA = Non-Standalone，非独立组网。

```
5G模块
 ├─ 4G LTE：负责主要控制、注册和信令
 └─ 5G NR：主要提供高速数据能力
        ↓
     4G核心网 EPC
```

可以理解为：

> 在现有4G网络基础上增加5G基站，4G担任“总指挥”，5G负责提升数据速度。

特点：

- 运营商部署速度快、成本低
- 需要4G网络作为锚点
- 状态中可能同时出现LTE和NR信息
- 早期5G网络大量采用这种方式

## SA：独立组网

SA = Standalone，独立组网。

```
5G模块
   ↓
5G NR基站
   ↓
5G核心网 5GC
```

它不依赖4G作为控制锚点，注册、信令和数据都可以通过完整的5G网络完成。

特点：

- 完整的5G网络架构
- 更适合低时延、网络切片等5G原生能力
- 需要运营商部署5G核心网
- 是否能用仍取决于SIM卡、运营商网络和当地覆盖

## 9. 一次真实AT输出怎么读

在开发板上执行：

```bash
echo -en 'AT+QICSGP?\r\n' > /dev/ttyUSB3 | cat /dev/ttyUSB3
```

其中，`echo` 把AT指令发送给5G模块，`cat` 持续读取模块返回的数据，按 `Ctrl+C` 才会结束读取。

### 9.1 APN配置

```text
+QICSGP: 1,3,"cmnet","","",0
+QICSGP: 11,3,"ims","","",0
OK
```

- `1`、`11`：配置编号CID。
- `3`：使用IPv4/IPv6双栈。
- `cmnet`：中国移动常用的上网APN。
- `ims`：运营商用于语音、短信等IMS业务的APN，一般不是普通上网使用的APN。
- 用户名和密码为空，最后的 `0` 表示不使用PAP/CHAP认证。

`OK` 只表示查询成功。这里查到的是APN配置，不能据此判断模块已经拨号成功或已经取得IP地址。

### 9.2 信号强度

```text
+CSQ: 20,99
```

- `20` 是粗略信号等级，约为 `-73 dBm`，本次信号不差。
- 第二个值 `99` 表示误码率未知，不是误码率99%。

维护5G连接时，后面 `QENG` 中的 `RSRP`、`RSRQ` 和 `SINR` 比 `CSQ` 更有参考价值。

### 9.3 当前5G驻网状态

```text
+QENG: "servingcell","NOCONN","NR5G-SA","FDD",
460,00,000008701,2,0001,154810,28,30,-82,-9,16,-5,45,0
```

目前先关注这些字段：

| 字段 | 含义 |
| --- | --- |
| `servingcell` | 当前正在驻留的服务小区 |
| `NOCONN` | 已注册并驻留，但当前没有业务数据，处于空闲状态 |
| `NR5G-SA` | 当前使用5G独立组网 |
| `FDD` | 当前使用频分双工方式 |
| `460,00` | 中国移动 |
| `28` | 5G n28频段 |
| `30` | 下行带宽30 MHz |
| `-82` | RSRP，接收信号功率，本次较好 |
| `-9` | RSRQ，接收信号质量，本次正常 |
| `16` | SINR，信号与干扰的对比，本次较好 |

`NOCONN` 不等于“没有注册网络”。它表示模块已经驻留在小区，只是当前没有数据传输；产生网络流量后可能进入 `CONNECT` 状态。

从这份输出可以判断：模块已经注册到中国移动5G SA网络，驻留在n28小区，信号总体正常，`cmnet` APN也已配置。但还不能判断拨号、IP地址、路由和实际访问互联网是否成功。

### 9.4 为什么输出中还出现其他指令的结果

```text
+CME ERROR: 3
```

错误码 `3` 表示“当前操作不允许”。结合项目代码定期发送AT指令的顺序，它很可能是 `AT+QNETDEVSTATUS=1` 的返回，但这份混合输出不能单独证明。

平台程序运行时也在使用 `/dev/ttyUSB3`，所以 `cat` 可能同时读到程序定期查询的 `CSQ`、`QNETDEVSTATUS` 和 `QENG` 结果。不要长期让 `cat` 和平台程序同时读取该串口，否则 `cat` 可能抢走本应由平台程序接收的AT响应，造成超时或解析错位。
